Current shelf / الرف الحالي: —
1) Scan the shelf label (e.g. A03-2) or tap a shelf on the map.
2) Scan each parcel — it goes on that shelf.

Parcel list (client ID, name, weight, route) / قائمة الطرود

Paste rows from Excel, one parcel per line, columns in this order: tracking, client ID, client name, weight kg, route (GZ / HK / SEA). New rows are added; matching tracking numbers are updated. Parcels already on shelves pick up their details automatically.

Layout setup / إعداد المستودع

Shelf code = aisle letter + bay + level, e.g. A03-2. Level 1 is the floor.
